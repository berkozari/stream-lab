**Evidence:** static review of the user-supplied `streamlab-STREAM-009.1-source.zip` (701 archived paths) after STREAM-008.9 merge, 2026-11-27. This is an **audit baseline, not a production readiness sign-off**. No production source, database migrations, dependencies, storage objects, or live environments were changed. ## Findings, priority and assigned work

Priority means **risk if deployed as-is**, not proof of an exploit. P1 = must decide/fix before public production; P2 = important hardening; P3 = documentation/quality. Findings already described in `docs/stream-008-security-data-quality.md` and `docs/stream-007-security-performance-review.md` are carried forward, not rediscovered vulnerabilities.

## Recommended execution order / definition of done

1. **009.2 — Auth/API hardening**: remove reusable sample secrets, coordinated Redis limits, trusted proxy policy, auth replay and rate-limit tests; do not change successful CSRF/session/ownership contracts.
2. **009.3 — Upload/transcoding worker reliability**: realistic resource budgets, capacity gates, transient vs terminal error behavior, queue/lease/shutdown regression; no schema change without a clear concurrency failure case.
3. **009.4 — Database, Redis, analytics lifecycle**: read-only staging query plans first; explicit retention decision and safe migration/cleanup strategy second; no speculative indexes or production data purge.
4. **009.5 — Logs/metrics/health**: request-ID middleware order and tests; redacted worker logs, queue-health/latency metrics and actionable alert conditions.
5. **009.6 — Security, integration and performance gates**: real JWT/session + PostgreSQL tests, Redis multi-instance limiting tests, upload/worker failure tests, browser E2E, baseline load profiles, and CI stages. Separate destructive/writable tests from read-only ones.
6. **009.7 — Production config/readiness**: deployable container definitions, TLS/origin/security config, non-root/media sandboxing, migration and backup/restore runbook, secret provisioning and refreshed README.
7. **009.8 — Milestone closure**: no P1 unresolved without an explicitly accepted reason, full regression, migration status, resource/latency evidence, CI/PR review, source hygiene and manual merge.
